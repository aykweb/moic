https://aykweb.github.io/moic/

## 制作年
2026年

## 使用技術
- **HTML5** / **CSS3**
- **JavaScript ES6** (Vanilla JS)
- **Figma** : デザイン制作

## 制作環境
- **MAMP**
- **macOS**
- **VS Code**
- **GitHub** : 履歴管理

## 制作のポイント
- **アクセシビリティの確保**  
WAI-ARIAやinert属性を用い、スクリーンリーダーやキーボードでの操作を考慮。

- **JavaScriptによるパーツ共通化**  
Fetch APIによりヘッダー・フッターを共通化し、保守性を向上。

- **サイト内検索機能**  
Googleカスタム検索を導入。  
（本サイトは架空のコンテンツにつき、クローラーの巡回を制限しており、検索結果は表示されません。）

- **保守性の高いCSS設計**  
カラー、余白、フォント等にCSS変数を活用。
